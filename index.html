Phased Deployment Plan
3-phase rollout for Prestige Tech Park, Coimbatore — from sensor baseline to full optimisation.
System Architecture
Four integrated layers: Sense → Learn → Model → Act. Mirrors Schneider's EcoStruxure three-tier model (connected products → edge control → apps/analytics) — deployed per building, retrofit-ready.
EcoStruxure Aligned
📡
Layer 1 — SENSE
Low-power RISC-V MCU sensor nodes (mmWave occupancy, NDIR CO₂, SHT31 Temp/RH, Lux, CT-clamp sub-metering) running quantized INT8 tinyML inference on-chip. Only derived comfort score + occupancy state transmitted — never raw data. On-device latency <5 ms vs 200 ms–2 s cloud round-trip.
RISC-V MCU (GD32VF103-class)mmWave Radar Occupancy NDIR CO₂ (SCD30)SHT31 Temp/RH Ambient LuxCT-Clamp Sub-meter INT8 Quantized Model <50 KB
↕ Derived events only (occupancy state + comfort score) — never raw streams · BLE/WiFi · <1 KB/event
🏢
Layer 2 — LEARN (Building Gateway)
One Raspberry Pi–class gateway per building. Aggregates sensor nodes, trains the local comfort/energy model on building-specific data, and executes BMS actuator commands. Model continuously improves with new occupancy + comfort-vote data. Handles BACnet/Modbus bridging to existing HVAC/lighting hardware.

Layer 4 — ACT (Grid-Responsive Controller + Facility Dashboard)
Constrained optimisation shifts flexible loads (pre-cooling thermal mass, battery charge/discharge, non-critical lighting) away from DISCOM peak ToD windows, bounded by comfort score ≥ threshold. 1-tap occupant feedback (too warm / fine / too cold) closes the training loop — each vote is a labeled comfort-model training sample.

🔒 Why Edge Intelligence, Not Cloud?
• Latency — 200 ms–2 s cloud round-trip too slow for real-time HVAC comfort control; on-device = <5 ms
• Connectivity — tier-2/3 buildings have intermittent internet; cloud dependency breaks deployment
• Privacy — raw occupancy traces reveal who is where, when (DPDP Act concern for tenants)
• Bandwidth — streaming raw sensor data from 100s of nodes per building is expensive and wasteful
✅ EcoStruxure Alignment
• Connected Products → RISC-V sensor nodes (SENSE)
• Edge Control → Building gateway with local model + actuators (LEARN)
• Apps / Analytics → Digital twin + retrofit + dashboard (MODEL + ACT)
• Electricity 4.0 — Decarbonize via digitize + electrify + distributed intelligence
